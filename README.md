# Hysteria2 Filter

Фильтр конфигов для **Happ VPN** на GitHub Pages: вставляешь подписку или конфиги — сервис в реальном времени оставляет только `hysteria2://`.

## Возможности

- Загрузка подписки по ссылке (raw.githubusercontent.com и любые URL через CORS-прокси)
- Вставка конфигов напрямую (vless, vmess, ss, trojan, hysteria2, tuic...)
- Реальном времени фильтр: показываются только `hysteria2://`
- Поиск по названию сервера / адресу / порту
- Статистика: всего / hysteria2 / другие / показано
- Копирование отдельных конфигов, всех сразу, скачивание в .txt
- Всё работает локально в браузере — конфиги никуда не отправляются
